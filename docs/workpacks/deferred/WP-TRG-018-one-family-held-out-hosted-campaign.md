# WP-TRG-018: One-Family Held-Out Hosted Campaign

- Status: deferred
- Owner: unassigned
- Reviewer: independent reviewer required
- Risk tier: G3

## Entry condition

The same named family has independently reviewed development terminal evidence under an unchanged frozen policy, and the user selects this held-out scope.

## Goal

Evaluate only that family's predeclared held-out rows, then produce a bounded terminal evidence review.

## Scope

Use frozen split/order, observations, policy, model, executor and gates; obtain fresh preflight, unused paths and itemized G3 authorization. Run serially within the predeclared request cap. Preserve split isolation and do not read a held-out answer to change a later request.

## Stopping rule and ledger update

Stop on the first predeclared terminal failure. After independent terminal review, add a compact row to the hosted experiment registry and update the case portfolio only as a read-only relationship. State the denominator and one allowed conclusion; do not aggregate across policies or claim generic CAD capability.

## Out of scope

Development tuning, retries, replacement rows, prompt/card/model changes, runtime promotion, external data or a benchmark claim.
