# WP-M26-004: Multi-Inner-Loop Pocket Governance Promotion

- Status: done
- Milestone: M26
- Owner: Codex

## Goal

Decide whether exactly the six reviewed M26 experimental candidates should
become active self-authored governance cases under a new family-specific ADR.

## Scope

- Add only authoritative metadata, deterministic reference scripts, case cards,
  registry pointers, and a narrow library-audit extension for the six frozen
  records.
- Re-run family and library replay audits without changing executable manifests.

## Compatibility constraints

Offline-only. No automatic manifest, provider, training, runtime, parser,
helper, SDK, IR, external-data, or generic multi-contour admission.

## Acceptance

- A dedicated ADR limits maintenance to the six frozen records.
- All six retain exact sequence, hash/path, split, replay, editability, and
  semantic evidence after promotion.

## Result

Completed offline on 2026-08-05. ADR-0031 promotes exactly the six frozen
records to active self-authored governance cases with reference scripts, case
cards, registry pointers, and a scoped library audit extension. Executable
manifests, Harness, provider, training, and runtime remain unchanged.
