# Q03/Q04 Execution Knowledge

This directory holds reviewed, reusable knowledge for safe script execution,
geometry gates, diagnostics and bounded repair decisions. Entries state their
input signal, success/failure signature, stop condition and evidence boundary.

It is not a catalogue of CAD feature helpers or a place to promote a one-off
reference-script workaround. A proposed helper, IR or SDK remains subject to
the separate adoption gates in
[modeling-knowledge-adoption.md](../../../architecture/v1/modeling-knowledge-adoption.md).
