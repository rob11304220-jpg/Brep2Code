# Q01 B-Rep Observables

This directory holds reviewed, tool-grounded definitions of what the Harness may
observe from B-Rep input: measurement method, units/frame, ambiguity and
fail-closed conditions. It does not label a feature or infer a construction
history.

Add an entry only when a concrete Q01 decision needs a stable observation that
is not already fully defined by a probe contract. Link the probe contract,
positive/negative evidence, and any downstream operation unit that consumes it.
See [the knowledge-base architecture](../../../architecture/v1/knowledge-base-architecture.md).
