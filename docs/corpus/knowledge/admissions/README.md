# Admission Records

Admission records are immutable development-side evidence sources governed by
the [v1 contract](../../../architecture/v1/contracts/admission-record-v1.md).
They bind reviewed source materials to a bounded mechanism and are not case
authority, executable input, runtime knowledge, or hosted input.

The selector-ambiguity pilot records the development oracle and discriminating
control directly. Its held-out control is represented exclusively by existing
reviewed, hash-pinned documentary evidence; its fixture is never read or
executed by the admission audit.
