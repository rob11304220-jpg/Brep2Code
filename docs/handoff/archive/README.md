# Historical Handoff Snapshots

Files in this directory are immutable records of a prior session. Their
embedded `Status`, `Next`, `Blockers`, owner and active-workpack language
describe the state at the time of archival only. They are not current lifecycle
declarations and never authorize implementation, runtime changes or hosted
requests.

For current work, start with [`../../workflow/status.md`](../../workflow/status.md)
and follow [`../../workflow/navigation.md`](../../workflow/navigation.md).
