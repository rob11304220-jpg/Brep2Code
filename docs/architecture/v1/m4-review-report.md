All primary failures execute successfully, write readable STEP output, and fail only bbox, volume, and topology comparison gates because the default scaffold emits the baseline box. They are therefore expected coverage evidence, not probe, CAD-backend, or gate malfunctions.

## Decision

- Do **not** introduce a modeling IR, project-level CAD SDK, or CAD workplace abstraction now. The corpus does not demonstrate a need: all six failing primary cases have a working local replacement script.
- Keep the current probe/action space and geometry gates for the next increment. There is not yet hosted-model evidence identifying a missing probe, action, prompt, or gate.
- Prioritize runtime execution isolation before enabling a hosted provider. The current executor uses a revision workspace as `cwd`, but this is not a security boundary for arbitrary Python generated by a provider.
