# M27 Oriented Rounded-Slot Evidence Review

## Evidence reviewed

The six frozen `oriented-rounded-slot-v1` experimental candidates passed
clean-directory hash stability, geometry replay, exact four-operation sequence
agreement, declared +X/+Y axis agreement, four editability mutations,
through-cut/single-solid semantic checks, and family-isolated 3/3 splits.

## Supported boundary

The evidence supports only a deterministic XY rectangular base with one
through rounded-slot cut whose cap-to-cap axis is explicitly declared as +X or
+Y. The development +X and held-out +Y rows establish that this frozen
two-frame distinction is observable under the existing gates.

## Not supported

It does not establish arbitrary orientation, rotated support planes, splines,
generic sketch-frame recognition, generic profile recognition, native history,
or B-Rep-to-sequence recovery. It does not justify a manifest, provider,
training, or runtime change.

## Disposition

Select only a separate family-specific governance-promotion workpack. It may
promote exactly the six frozen records if a new ADR, reference scripts, case
cards, registry pointers, and scoped library audit all pass.
