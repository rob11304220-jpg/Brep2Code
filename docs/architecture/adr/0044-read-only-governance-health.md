# ADR-0044: Read-Only Governance Health Snapshot

- **Status**: Accepted
- **Date**: 2026-08-07

## Decision

Add a dependency-free, read-only command that summarizes lifecycle counts,
ledger dispositions, and governance-audit status in Markdown or JSON.

## Consequences

The project gains a reproducible process-health view without creating a
productivity score, changing repository state, or making claims about Harness
or hosted-provider performance.
